# 2026-06-04

## Multi-route conflict modals — Modal 1, 2, 3

Dispatchers can now assign the same truck or driver to more than one route — and the app catches it. Three new modals handle the two conflict axes:

- **Modal 1 — Confirm Truck Selection**: fires when the same truck is picked for a second route. Read-only caution — shows the conflicting route card (truck name, gal · compartments · products, driver, order count, route-colour left rail). Confirm always enabled; Cancel reverts the selection.
- **Modal 2 — Set Route Sequence**: fires when the same driver is selected for a second route. Hard block — Confirm stays greyed out until both routes have a start time set. Sequence badges (1, 2, …) live-update as times change, derived from start time only (earlier start = Route 1). Collision rule: a time already taken by the other route is dimmed and unselectable in the picker.
- **Modal 3 — Route Start Time**: accessible from the ⋮ menu on any route card ("Route Start Time" item, only visible when that driver has a conflict). Single time input for this route; same-driver routes shown read-only below for context. Same collision rule applies.

Start time is the single source of truth for sequence — never stored separately, always derived at render time.

The `TimePicker` component was extracted from the Create Order modal into a shared `components/time-picker.tsx` with a new `disabledTimes` prop that blocks already-taken time slots.

## Save Map View + map control polish

- **Save Map View button** (MapPinned icon, 32px) added to the floating map controls, below the lasso. First click saves the current camera state — center, zoom, bearing, pitch — to `localStorage`. Clicking again flies the map back to the saved view. State persists across page refreshes.
- **Lasso icon updated** to `LassoSelect` (the version with a cursor graphic), replacing the plain `Lasso` icon.
- **Compass button removed** from the control stack.
- **All control buttons standardised** to 32px (previously mixed 32px and 40px).
