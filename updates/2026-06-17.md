# 2026-06-17

## Modal 2 — "Set Start Time" (driver conflict, redesigned)

Modal 2 (the modal that fires when a dispatcher assigns a driver who already has another route that day) was completely redesigned. The old approach was a connector/FLIP sequence-reorder visualization — the new design drops all of that and replaces it with a simpler intent: **set a start time for each route, and the sequence falls out naturally**.

### What changed

**Old:** A single connector line showing the two routes with drag handles to reorder them.

**New:** One accordion card per conflicting route. Each card shows:

- **6px accent rail** on the left edge in the route's own pastel color
- **Header row** (full-row clickable, hover `#333`): truck icon + name + specs line (`N,NNN gal · N Compartments · N Products`) on the left; `N Orders` badge + chevron on the right. If no truck is selected, shows "No Truck Selected" in muted `#737373`.
- **Body** (expands/collapses with the chevron): `TimePicker` to set the start time + a "See All Orders" toggle button.
- **Orders table** (reveals when "See All Orders" is clicked): two columns — **Stops** (sequence number + L/D/T type badge + stop name) and **Planned Qty** (`{n} gal`). Badge colors: Load `#189FFC`, Delivery `#25B8A7`, Transfer `#737373`.

**Confirm & Proceed** stays disabled (`opacity 0.5`) until every route in the modal has a start time set. The disabled-times logic ensures no two routes can share the same start time.

### TimePicker fix

The TimePicker dropdown was rendering behind sibling route cards. Root cause: the modal creates a stacking context, so z-index alone wasn't enough. Fixed by rendering the dropdown panel via a **React portal** (`createPortal` to `document.body`) at `z-index 10200`.

### Accordion animation

Expand/collapse on the route cards and the orders table now animate with `grid-template-rows: 0fr → 1fr` (280ms, `cubic-bezier(0.4, 0, 0.2, 1)`). Chevron rotates 180° on expand, synced to the same curve.
